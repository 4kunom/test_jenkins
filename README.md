# 마크다운(Markdown) 사용법

## 1. 제목 (Headings)

# H1 - 가장 큰 제목
## H2 - 제목
### H3 - 소제목
#### H4
##### H5
###### H6 - 가장 작은 제목

---

## 2. 텍스트 포맷팅

**굵은 텍스트** (Bold)
*기울인 텍스트* (Italic)
~~삭제된 텍스트~~ (Strikethrough)
`인라인 코드` (Inline Code)

---

## 3. 목록 (Lists)

### 순서 없는 목록
- 항목 1
- 항목 2
  - 중첩 항목 2-1
  - 중첩 항목 2-2
- 항목 3

### 순서 있는 목록
1. 첫 번째
2. 두 번째
3. 세 번째

---

## 4. 링크와 이미지

[텍스트 링크](https://example.com)
![이미지 텍스트](https://example.com/image.jpg)

---

## 5. 인용 (Blockquote)

> 이것은 인용문입니다.
> 여러 줄의 인용도 가능합니다.

---

## 6. 코드 블록 (Code Block)

```python
def hello():
    print("Hello, World!")
```

```javascript
const greeting = "Hello, Markdown!";
console.log(greeting);
```
